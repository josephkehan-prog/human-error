NAME

number-keyboard - a number pad you can use in any app

SYNOPSIS

number-keyboard [--haptics] [--click] [--return] [--layout] [--theme]

DESCRIPTION

The iPhone keyboard hides digits behind the 123 key. That is slow when you are typing a lot of numbers.

Number Keyboard - Digits is a keyboard you turn on once in Settings. Hold the globe key, pick it, and you get a number pad in whatever app you are in.

123 456 789 globe0del

0 sits under 8, like a phone pad. On iPad and in landscape the keys line up in one row.

OPTIONS

--haptics
A small tap on each key. Needs Allow Full Access. Nothing else does.
--click
The system key click sound.
--return
Show or hide the Return key.
--layout
Number pad grid or a single row.
--theme
Auto, Dark and Light are free. Midnight, Paper and Mint come with Pro Themes.

These are switches in the app, not real flags. I just like man pages.
