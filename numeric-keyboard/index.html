Number Keyboard - Digits

Numpad and keypad for any app. A number pad keyboard for iPhone and iPad.

COMING SOON  Not on the App Store yet.

NAME

number-keyboard - a number pad you can use in any app

DESCRIPTION

The iPhone keyboard hides digits behind the 123 key. That is slow when you are typing a lot of numbers.

Number Keyboard - Digits is a keyboard you add in Settings. Switch to it with the globe key and you get a number pad in whatever app you are in.
