NAME

human-error - bringing tomorrow's problems today

SYNOPSIS

human-error [--build] [--break] [--fix] [--ship] [--repeat]

DESCRIPTION

Human Error is a one-person software studio. I build apps for iPhone and iPad in Swift.

Every bug starts with a person. So does every fix. This is where I do both.

OPTIONS

--build
Write the thing.
--break
Find out what is wrong with the thing.
--fix
Make it right. Introduce two new problems.
--ship
Send it to the App Store anyway.
--repeat
On by default. Cannot be turned off.
